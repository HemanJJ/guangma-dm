|---|---|
| `index.html` | **$9,999 全包專案**（A4 一頁，可列印／存 PDF） |

## 數字來源

- **$9,999 版**：單包成本 $16｜售價 $35｜利潤 $19｜526 包回本
- **0 元版**：單包成本 $13｜售價 $35｜利潤 $22｜**70 包回本**（以年繳計算）
- **共同費用**：押金 $1,000（繳滿 2 年插頭歸你）｜開通 $500（一次性）｜月費 $100 內含 200 次／月，第 201 次起 $1／次
- 以上**未稅**，運費另計
